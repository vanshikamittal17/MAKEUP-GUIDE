💄 Makeup Guide

A simple and beginner-friendly makeup guide website designed to help users explore makeup techniques through easy steps and visual references.

✨ About the Project

Makeup Guide is a basic website that provides step-by-step makeup guidance along with product images to make beauty routines easier to understand and follow.

🌸 Features

- Easy-to-follow makeup steps
- Product images and visual references
- Beginner-friendly content
- Simple and clean user interface
- Easy navigation

🛠️ Technologies Used

- HTML5
- CSS3

🎯 Project Objective

The main objective is to create a simple platform that helps beginners understand makeup application techniques and explore suitable products.
